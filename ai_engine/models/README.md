# AI Engine Model Weights Directory

This directory is intended strictly for local cached model weights, tokenizer configs, and adapter checkpoints during development.

> [!CAUTION]
> **NEVER COMMIT BINARY MODEL WEIGHTS TO GIT.**
> All files ending with `.pt`, `.bin`, `.safetensors`, `.onnx`, `.ckpt`, or `.h5` are strictly ignored by `.gitignore`.
> Heavy model checkpoints must be downloaded at runtime from Hugging Face or public model hubs.
